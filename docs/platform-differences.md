# Windows 与 macOS 的功能差异

截至 2.2.3。两端共用同一份 Go 代码、网页界面和 `~/.tolk/config.json`，差别只在需要系统能力的地方。

## 两端一样的

| 功能 | 说明 |
|---|---|
| 翻译引擎 | Google、微软、DeepL、AI 翻译（OpenAI 兼容）、Achord 内置引擎 |
| 语言 | 37 种，同一张语言表 |
| 主窗口翻译 | 自动检测源语言、交换语言、复制译文 |
| 复制两次呼出翻译 | Windows 是 Ctrl+C+C，macOS 是 ⌘+C+C（按住修饰键连按两下 C），间隔可调；检测方式见下表 |
| 截图翻译 | Ctrl+X+X（macOS 是 ⌘+X+X）框选屏幕区域，在本机识别文字，译文贴回图片原来的位置；可以对照原文、提取原文、复制图片、钉到屏幕上。截图不上传，只有识别出的文字发给翻译服务 |
| 全局快捷键 | Ctrl/⌘ + Shift + C：翻译剪贴板里的文字 |
| Mini 模式 | 在鼠标旁弹出气泡显示译文 |
| 输入助手 | 选中文字 → 快捷键 → 多语言候选 → 替换回去（见下表） |
| 主题 | 跟随系统、浅色、深色、粉色；原文和译文字号可调 |
| 开机自启、托盘、控制台日志、在线更新 | 更新包都用 Ed25519 / Sparkle 签名校验 |
| 设置和更新渠道 | 沿用老版的配置文件，升级不丢设置 |

## 只有 macOS 有的

| 功能 | 原因 |
|---|---|
| Apple 本地翻译（离线，不用 API Key） | 依赖系统的 Translation 框架（macOS 15.1+） |
| 权限引导 | 只对 macOS 有意义 |

这些由 `macos/helper` 里的 Swift 小助手提供。

## 复制两次与截图：两端的做法

| | macOS | Windows |
|---|---|---|
| 复制两次的检测 | 默认看剪贴板变化，不需要权限；打开「系统级 ⌘+C+C」后改由小助手的事件监听（CGEventTap）看按键，需要辅助功能权限 | 低级键盘钩子看按键，不需要权限（`doublecopy_windows.go`）；钩子装不上、或前台是以管理员身份运行的窗口时，临时退回剪贴板变化检测 |
| 截图快捷键 | ⌘+X+X，小助手的事件监听，需要辅助功能权限 | Ctrl+X+X，和复制两次共用同一个键盘钩子（`screenshot_hotkey_windows.go`）；第一次 Ctrl+X 照常剪切 |
| 截屏与界面 | 小助手，需要录屏权限 | PowerShell 截图界面（`internal/screenshot`）；控件编译后缓存在 `%LocalAppData%\Tolk\screenshot`，快捷键开着时提前预热 |
| 文字识别 | Vision | Windows 自带的 `Windows.Media.Ocr`，需要系统里装有对应语言的 OCR 语言包 |

## 只有 Windows 有的

| 功能 | 说明 |
|---|---|
| 安装程序（Inno Setup）与原地升级 | 沿用老版的 AppId 和安装目录 |

## 输入助手：两端的做法

| | macOS | Windows |
|---|---|---|
| 由谁实现 | Swift 小助手（`macos/helper`） | 主程序自己（`ia_windows.go`、`internal/winsel`） |
| 需要的权限 | 辅助功能 | 无 |
| 默认快捷键 | ⌥⇧Space | Alt+Shift+Space（可选 Ctrl+Alt+Space / T / G / J） |
| 读选中的文字 | 辅助功能接口；Chromium 系应用先打开它的辅助功能树再重试；读不到时改用复制取词（模拟 ⌘C，随后还原剪贴板，2.1.1 起） | UI 自动化（UIA）；读不到时临时按一次 Ctrl+C，随后还原剪贴板（微信等走这条路） |
| 替换 | 辅助功能接口精确写入；不行再粘贴（⌘V）；再不行复制译文 | 粘贴（Ctrl+V），0.5 秒后还原剪贴板；粘贴前确认前台应用、焦点控件没变；UIA 读到的原文必须读得到且和现在一字不差；Ctrl+C 读到的内容以换行结尾（Sublime、VS Code 在没选中时会复制整行）时只给译文、不替换；不行就复制译文并提示 |
| 候选面板 | 不抢焦点的 NSPanel，按键靠事件监听拦截 | 不抢焦点的浮层窗口，按键和鼠标靠低级键鼠钩子拦截，只在面板打开时安装 |
| 按键 | ↑↓ 回车 Esc，⌘1–⌘6 直接选，⌘C 只复制 | ↑↓ 回车 Esc，Ctrl+1–Ctrl+6 直接选，Ctrl+C 只复制 |
| 按住 ⌥ 看调试信息 | 有 | 没有（Windows 上 Alt 单独按下会激活菜单栏） |
| 默认黑名单 | 终端、钥匙串、密码管理器（Bundle ID） | Windows Terminal、cmd、PowerShell、1Password、Bitwarden、KeePass（程序文件名） |
| 自动显示（实验） | 有 | 有，但只对提供选区接口的应用有效：自动模式从不替用户按键，所以不会走「按 Ctrl+C」那条路 |
| 管理员身份运行的应用 | 无此限制 | Windows 会拦下普通程序对它的读取和按键；Tolk 会提示「请以管理员身份运行 Tolk」 |
| 缓存 | 本地缓存（⚡），键含引擎指纹 | 同一套，文件在 `%LocalAppData%\Tolk` |

共用的部分：设置（`tolk.input_assist`）、目标语言规则、同源语言隐藏、网址 / 邮箱不翻译、每个目标语言并行翻译、单条失败可点击重试、缓存键。这些在 `internal/inputassist` 里，两端的结果一致。
