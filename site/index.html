不用切窗口，也不用粘贴

Tolk 平时待在托盘或菜单栏里，需要的时候一按就到，看完就走。

复制两次呼出翻译

在浏览器、PDF、聊天软件里选中文字，按 Ctrl+C+C（Mac 上是 ⌘+C+C，按住 ⌘ 连按两下 C），译文窗口直接出现。

截图翻译

按 Ctrl+X+X（Mac 上是 ⌘+X+X）框选屏幕任意区域，在本机识别文字，译文贴回图片原来的位置，还能钉在屏幕上。

输入助手

在输入框里写好中文，选中后按 Alt+Shift+Space，挑一个外语候选，直接替换回去。回邮件、发消息都顺手。

Mini 模式

不想弹出大窗口，就让译文以小气泡出现在鼠标旁边，看一眼就消失，不打断手上的事。

多家翻译服务

Google、微软、DeepL、AI 翻译（任何 OpenAI 兼容接口）随时切换；macOS 还能用系统自带的离线翻译。支持 37 种语言。

浅色、深色、粉色

跟随系统或手动选主题，原文和译文字号分别可调。新版本在后台下好再提示，下载的文件都会校验签名。

安装说明

下载后按下面几步装好。设置保存在本机，升级不会丢。

Windows

Windows 10 / 11，64 位

  1. 下载 Tolk-setup-windows_2.2.3.exe，双击运行。
  2. 如果出现「Windows 已保护你的电脑」，点 更多信息 → 仍要运行。
  3. 装好后 Tolk 会出现在右下角托盘，左键打开主窗口，右键是菜单。
截图翻译用的是 Windows 自带的文字识别，需要系统里装有对应语言的 OCR 语言包。

macOS

Apple 芯片和 Intel 通用

  1. 打开 Tolk-2.2.3-macos.dmg，把 Tolk 拖进「应用程序」。
  2. 第一次打开如果提示无法验证开发者，到 系统设置 → 隐私与安全性，在页面下方点 仍要打开。
  3. 按 Tolk 的引导打开 辅助功能 和 录屏 权限，输入助手、截图翻译和系统级 ⌘+C+C 监听要用到。
从 2.2.2 及更早版本升级的，需要手动装一次 2.2.3，并重新授予一次权限；之后的版本都会在软件里自动更新。
